# Olist E-commerce Sales Analysis

## Project Overview
This project analyzes e-commerce data to understand sales performance, product popularity, payment preferences, order statuses, customer locations, and customer satisfaction.

## Tools Used
- MySQL 8.0
- Microsoft Power BI
- SQL
- Data visualization and dashboard reporting

## Project Objectives
- Calculate key business metrics.
- Identify top-performing product categories.
- Analyze monthly sales trends.
- Understand payment method preferences.
- Examine order status distribution.
- Identify customer states contributing the most revenue.
- Find best-selling products.
- Analyze customer review scores.

## SQL Analysis
The project includes eight analyses:
1. Key business metrics
2. Top 10 product categories by revenue
3. Monthly delivered-order revenue
4. Payment method analysis
5. Order status analysis
6. Top 10 customer states by revenue
7. Top 10 best-selling products
8. Customer review analysis

## Power BI Dashboard
The dashboard contains:
- Five KPI cards
- Five charts
- A date slicer
- Interactive sales analysis

## Key Findings
- Total orders: 99,441
- Unique customers: 96,096
- Total product revenue: 13,591,643.70
- Total freight: 2,251,909.54

## Project Files
- `olist_sales_analysis.sql` — SQL queries
- `Olist_Ecommerce_Sales_Analysis.pbix` — Power BI dashboard

## Notes
Revenue figures represent product prices unless explicitly stated otherwise. Results may vary when dashboard filters are applied.
